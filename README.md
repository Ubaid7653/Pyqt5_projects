# Calculator

A simple and user-friendly **Calculator** application built using **PyQt5**. This desktop GUI application allows users to perform basic arithmetic operations with a clean and intuitive interface.

## Features

- Perform basic arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Clear and reset functionality.
- Real-time display of inputs and results.
- Responsive and visually appealing user interface.
- Error handling for invalid inputs (e.g., division by zero).

## Technologies Used

- **Python**: The programming language used for logic and functionality.
- **PyQt5**: For creating the graphical user interface (GUI).
